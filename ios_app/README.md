# 文件清理 · iOS 端

「txt 文件清理」工程的 **iOS 原生客户端**（Swift / SwiftUI），功能与安卓端、电脑端保持对齐。

## 功能对照（参考安卓端）

| 模块 | 说明 |
| --- | --- |
| 扫描文件 | 通过系统「文档选择器」选择文件夹（iOS 隐私沙盒限制，只能访问你主动选取的目录），递归枚举并按文件名解析 |
| 文件名解析 | 书名 / 作者 / 进度 / 来源 提取，正则与电脑端 `regex_parser.py` 对齐 |
| 编码识别 | BOM + UTF-8 合法性校验 + GB18030 兜底（iOS 原生支持 GB18030） |
| 简繁 / 拼音 | 使用 `CFStringTransform`，无需第三方库 |
| 文库列表 | 列表 / 合集两种模式，搜索、排序（书名/作者/进度/来源/大小/扫描顺序）、前缀筛选、分页、逐条勾选/标星/预览/重命名 |
| 勾选重复（五则规则） | 完全相等 / 纯数字进度 / 含中文进度保护 / 完结特例 / 最大文件 / 完结+N番外，可开关内置规则并新增自定义条件-动作规则 |
| 一键清理 | 自动标记重复文件 → 确认删除（可选「同时删除磁盘文件」或「仅移除记录」） |
| 关键词替换 | 扫描/解析阶段对文件名与字段做精确字符串替换（预置水印/推广语规则） |
| 操作日志 | 记录删除、标记、规则变更，可查看/清空 |
| 设置 | 主题、阅读字号、预览滚动条、默认扫描参数、合集过滤默认值 |

所有数据保存在本机沙盒内的 SQLite 数据库（`Documents/file_scanner.db`），不上传任何服务器。

## 构建与运行

> 本工程为纯原生 Swift/SwiftUI 实现，需 **macOS + Xcode 15+** 才能编译运行（Windows 下无法构建 iOS 包）。

1. 用 Xcode 打开 `FileScanner.xcodeproj`。
2. 选择设备/模拟器（iPhone 或 iPad，部署目标 iOS 16+，NavigationStack 依赖）。
3. 如需真机运行，修改 `PRODUCT_BUNDLE_IDENTIFIER`（默认 `com.booksclean.app`）并配置签名团队。
4. `⌘R` 运行。

项目结构：

```
FileScanner/
├── App/            # @main 入口、导航路由、扫描状态
├── Core/           # 模型、SQLite 数据库、解析/去重/替换/编码/简繁 核心逻辑
├── Services/       # 扫描编排（文件夹枚举 + 解析 + 落库）
└── UI/             # SwiftUI 界面（首页/文库/配置/删除/一键清理/设置/帮助）
```

## 与安卓端的差异说明

- **文件访问**：安卓端通过 SAF 可深度访问外部存储；iOS 沙盒只能访问用户在「文档选择器」中显式选取的文件夹，删除/读取文件依赖该文件夹的安全作用域书签（已持久化，重装后需重新授权）。
- **编码/拼音**：安卓端使用 `opencc4j` / `pinyin4j`，iOS 端改用系统 `CFStringTransform`（繁简转换 + 拼音）与 `kCFStringEncodingGB_18030_2000`（GBK/GB18030 解码），效果等价、零依赖。
- **去重/解析逻辑**：文件名解析、`DupRuleLogic` 五则规则、`KeywordReplace` 规则均与安卓端逐行对齐，保证多端结果一致。

## 已知限制

- 预览大文件时一次性读入内存，超大文本建议先筛选。
- 若删除时提示「失败」，通常是该文件夹授权已失效或文件已被移动，数据库记录仍会移除。

# 鸿蒙模拟器运行命令（DevEco Studio 实测）

以下为 DevEco Studio 调用鸿蒙模拟器安装并启动 APP 的实际命令流程。
包名：`com.booksclean.app`，入口 Ability：`EntryAbility`（module `entry`）。

构建产物路径（DevEco 默认 signed 输出）：

```
D:\Harmony\HarmonyCleaner\entry\build\default\outputs\default\entry-default-signed.hap
```

## 完整安装运行流程（hdc）

```bat
@echo off
set HAP=D:\Harmony\HarmonyCleaner\entry\build\default\outputs\default\entry-default-signed.hap
set TMPDIR=data/local/tmp/%RANDOM%%RANDOM%

hdc shell aa force-stop com.booksclean.app
hdc shell mkdir %TMPDIR%
hdc file send "%HAP%" "%TMPDIR%"
hdc shell bm install -p %TMPDIR%
hdc shell rm -rf %TMPDIR%
hdc shell aa start -a EntryAbility -b com.booksclean.app -m entry
```

说明：
- `hdc shell aa force-stop` 先停掉旧进程，避免端口/实例冲突。
- `mkdir` 的临时目录每次需用不同随机串（DevEco 示例为 `d61136134f5d44bca02e75a0583c1e3e`）。
- `bm install -p <目录>` 安装该目录下的 hap；安装完即删临时目录。
- `aa start` 的 `-a EntryAbility -b com.booksclean.app -m entry` 为固定启动参数。
